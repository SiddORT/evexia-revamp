---
name: MR dashboard reporting policy
description: Scope of approved all-date Doctor balances and dashboard organization.
---

The MR dashboard is approved to report both oldest unpaid order age and days
remaining before the existing Doctor restriction. Keep current all-date Doctor
balances separate from FY/quarter order filters and full-year achievement.
This is read-only reporting over the authenticated MR's own saved obligations,
committed receipts and active credits, not a new ledger or a policy change.
It does not authorize new financial formulas, reconstructed receipts or sample
financial transactions.

**Why:** The user explicitly selected both age and remaining days and approved
Overview, Doctor payments and Performance views while preserving all existing
information and financial enforcement.

**How to apply:** Keep the compact restriction warning discoverable on Overview
and detailed balances in Doctor payments. Do not use a blocked-Doctor list as a
complete balance directory. This narrow dashboard approval does not silently
expand the separate Doctor Overview page's financial scope.
