description: Supplied-reference label content and the boundary between Settings samples and live order documents.

Box and Bottle label template setup in Settings is separate from Immunotherapy document actions. Supplied PDFs are visual specifications, not production backgrounds or sources of patient, order, batch or expiry data. Preserve their warning/instruction language without introducing clinical guidance or implying medical-content validation.

**Why:** The user explicitly separated Settings template setup from ongoing order-document work and excluded clinical calculations, inferred batch/expiry values and new regulatory claims.

**How to apply:** Keep sample details fictional and visibly marked. A new Settings preference must not silently activate live label printing or change saved orders; any live integration requires its own approved scope.
