One- and two-allergen bottles use the same category-ranked table as three-allergen
bottles: row 1, or rows 1 and 2 respectively. This is explicit configured-value
assignment, not permission to invent medical formulations, sample quantities,
extract/dilution ratios or concentration meanings.

**Why:** The user confirmed the smaller-bottle rule and explicitly restricted the
feature to configured clinical values at new applicable final placement.

**How to apply:** Keep defaults within the existing new-MR category/Mix scope.
Do not extend the policy to historical/unrestricted Admin compositions, globally
sort/repack bottle membership, or silently reapply after saved corrections.
Manual Admin review and explicit approval remain independent.
