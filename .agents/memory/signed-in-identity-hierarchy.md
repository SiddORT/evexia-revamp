name: Signed-in identity hierarchy
description: User's name-first/account-number-second profile requirement and authority boundary
---
Signed-in MR, protected Super Admin and staff profiles must show the saved name
first and the actual saved MR/EVX account number on a separate line underneath.
This supersedes the earlier instruction to hide staff account IDs. Staff
designation and authoritative role remain additional details, not replacements
for the name/ID hierarchy. Do not invent a personal name for Super Admin.

**Why:** The user explicitly requested this hierarchy after a legacy random MR
username appeared as the dashboard greeting/profile identity.

**How to apply:** Keep identity presentation tied to authoritative saved
ownership and actual login/account numbers, not cosmetic formatted identifiers,
Employee Codes, email, guessed directory links or UUIDs.
