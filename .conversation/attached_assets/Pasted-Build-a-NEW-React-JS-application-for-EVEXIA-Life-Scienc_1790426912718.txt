Build a NEW React JS application for EVEXIA Life Sciences.

IMPORTANT:
- Use React JS.
- Use JavaScript only.
- DO NOT use TypeScript.
- Use .js and .jsx files.
- Build clean, production-quality React code.
- Create reusable components.
- Keep components properly segregated.
- Do not over-engineer the application.

==================================================
PROJECT SCOPE
==================================================

For this first phase, ONLY build the authentication / portal-selection
experience.

Do NOT build dashboards or internal modules yet.

Required routes:

/
 /admin
 /mr
 /doctor


==================================================
EVEXIA BRAND
==================================================

EVEXIA is a Life Sciences / Healthcare organization.

The UI should feel:

- Professional
- Modern
- Premium
- Trustworthy
- Clean
- Enterprise-grade
- Healthcare / Life-Sciences oriented

Use the attached EVEXIA logo as the primary branding reference.

Do not redesign the logo.

Use the logo appropriately throughout the application.


==================================================
COLOR THEME
==================================================

Use a visual theme inspired by the provided EVEXIA logo and visual reference.

Primary visual colors:

- EVEXIA Red
- Orange
- White
- Light Grey
- Medium Grey
- Dark Grey / Charcoal

Red and orange should be accent colors.

Use white and light grey for the majority of the interface.

Avoid making the entire UI red or orange.

The overall visual direction should resemble a modernized version of the
provided reference:

- Clean cards
- White/light-grey surfaces
- Red/orange accents
- Subtle shadows
- Strong typography
- Clean spacing
- Professional navigation/interaction patterns

==================================================
ROLE-BASED IMAGES
==================================================

Use professional role-based visuals.

ADMIN:
A professional administrative/business operations person in formal
corporate attire.

MR:
A professional Medical Representative in formal professional attire,
with subtle pharmaceutical/life-sciences context such as a tablet,
professional bag, or medical information material.

DOCTOR:
A professional doctor wearing a white medical coat in a clean,
modern healthcare environment.

IMPORTANT:

All three images must have a consistent visual style.

Do not mix unrelated illustration styles and photographs.

Prefer clean, professional imagery that integrates with the UI.

The images should support the UI, not overpower it.
